# Triton Internship

## Day 1: Environment, Architecture & Repository Foundation

This branch contains the implementation for Day 1 of the Triton internship.

The task focused on setting up a clean Python project structure, configuring the development environment, and preparing the repository for future machine learning tasks.

### Project

Customer Churn Detection

### Objective

Create the initial foundation for a customer churn detection machine learning project.

The setup includes:

- Python virtual environment.
- Project dependency management.
- Standard project folder structure.
- Git-based version control.
- Basic documentation.

### Technologies Used

- Python 3.13
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter
- Pytest
- Git and GitHub
